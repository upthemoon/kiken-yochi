# 朝の KY

送電線工事の朝の危険予知 (TBM-KY) を、ベテランの職長の聞き方で作る道具です。
工種は 組立・解体・基礎・架線 (張線)・その他。表示は日本語を基本に、英語 (job briefing) にも切り替えられます。
Built with Claude: Japan 2026 (2026-11-02〜11-08) の期間中に作りました。

現場の責任者がその日の作業を話すと、Claude が足りない情報を聞き返し、天気予報と過去のヒヤリハットを引いてから、
KYT の 4 ラウンドに沿った用紙 (危険・とくに大事な危険・対策と確認する人・全員で指差し唱和する一言) と、
朝礼で確かめる項目 (体調・保護具など)、やさしい日本語の読み上げ版を作ります。

現場の位置は GPS か地名で取り、その場所の風速・突風・雷の予報と、気象庁の注意報・警報 (日本国内) を
画面上の黄色い帯で知らせます。洪水の警報・注意報(気象庁の別のデータ)は取得せず、対象外と画面・用紙に明記しています。この帯は Claude を使わないので、API キーがなくても動きます。
夕方にヒヤッとしたことを記録すると、次に同じ作業をするときの用紙に入ります。

作業の中止・続行の最後の判断は、現場の責任者が行います。この道具は判断を代わりにしません。

## 作業員の言語

責任者の画面は日本語 (英語にも切り替え可)。用紙は作業員の母語でも出せます (4 つまで同時)。
対応: ベトナム語・インドネシア語・フィリピン語・中国語 (簡体字)・ミャンマー語・ポルトガル語 (ブラジル)・ネパール語・クメール語。
並びは建設業の外国人労働者の国籍の多い順です (厚生労働省「外国人雇用状況」令和 7 年 10 月末)。
道具や部位の名前は、現場で聞く日本語の呼び名も括弧で添えます。端末にその言語の声があれば読み上げます。
見出しの訳は母語話者の確認前の下書きです。

## 動かし方

```
npm install
cp .env.example .env   # ANTHROPIC_API_KEY を書く
npm run dev            # http://localhost:8787
```

## 中身

- `src/ky.ts` 聞き取りと用紙づくり (Claude API・tool use・構造化出力)
- `src/weather.ts` 天気予報 (Open-Meteo・キー不要) と注意報・警報 (国土地理院の逆ジオコーダー → 気象庁の地域コード → 気象庁の警報データ)。1 時間ごとの予報の 10m 風速を、中止基準の 10m/s (10 分間の平均風速) と比べる目安として、超える時間と雷の時間を知らせる。発表中の注意報・警報は種類を絞らずに全部出す
- `src/nearMiss.ts` ヒヤリハットの記録 (手元の JSON)。`data/near_misses.sample.json` の例はすべて架空です
- `public/` 画面
